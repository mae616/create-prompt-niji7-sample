# create-prompt-niji7-sample

niji journey v7 向けのプロンプトを、Claude Code のスキルとして組み立てるサンプル。

「描きたいもの」を伝えると、niji journey v7 で出力できるプロンプト（英語/日本語）を生成します。

```
/create-prompt 春の公園で団子を食べている猫耳の少女
```

## 仕組み

ChatGPT のカスタム指示が「ひとつの長い指示」だったのに対し、Claude Code のスキルは
**ドメインカプセル**（世界観・画風・色彩・顔構造など）にルールを分けて持つことができます。

- ひとつのカプセルを変えても、他のカプセルに影響しない
- 競合したときは優先度（priority）で解決する
- カプセル単位で追加・削除・差し替えが可能

## カプセルの優先順位

プロンプト生成時は、常にこの順で判断します。

```
画風成立 ＞ 主役の視認性 ＞ 配色成立 ＞ 構造維持 ＞ 情報再現
```

入力情報をそのまま再現するより、**画面として成立すること**を優先します。

## 導入方法

このリポジトリは **[Claude Code](https://docs.claude.com/ja/docs/claude-code/overview) のスキル**として動きます。
利用には Claude Code（CLI）のインストールが必要です。インストール手順は公式ドキュメントを参照してください。

リポジトリの取得方法は3通りあります。やりやすいものをひとつ選んでください。

### 方法A: ZIP でダウンロードする（一番かんたん／非エンジニア向け）

1. このリポジトリのページ右上にある緑の **「Code」** ボタンを押す
2. メニュー下の **「Download ZIP」** を押す
3. ダウンロードした ZIP を解凍し、好きな場所（例: `~/Documents/create-prompt-niji7-sample/`）に置く

Git の知識は不要です。ただし「あとから本家の更新を取り込む」ことはできません。
試しに使うだけなら、まずこの方法で十分です。

### 方法B: git clone する（更新を追いかけたい人向け）

ターミナルを開いて、置きたい場所で以下を実行します。

```bash
git clone https://github.com/mae616/create-prompt-niji7-sample.git
cd create-prompt-niji7-sample
```

本家が更新されたら `git pull` で最新を取り込めます。

### 方法C: Fork する（自分用に育てて公開もしたい人向け）

カプセルを書き換えて自分のスタイルに育てる前提なら、Fork がおすすめです。

1. このリポジトリのページ右上の **「Fork」** ボタンを押す
2. 自分のアカウント配下にコピーが作られる
3. その自分のリポジトリを `git clone` する（手順は方法B と同じ、URLだけ自分のものに変える）

これで「本家から更新を取り込みつつ、自分のカスタマイズはGitHubに残す」という運用ができます。

### Claude Code を起動する

取得したフォルダに移動して、その中で Claude Code を起動します。

```bash
cd create-prompt-niji7-sample
claude
```

このフォルダ内で起動した Claude Code だけが、`/create-prompt` スキルを認識します。
（スキルは `.claude/skills/` に入っているため、別の場所で起動すると見つかりません）

## 使い方

`/create-prompt` は Claude Code の **スラッシュコマンド** です。
Claude Code を起動した状態のチャット欄で、`/` から始めて入力します。

### プロンプトを生成する

```bash
/create-prompt 猫耳の少女が窓辺で伸びをしている
```

### 修正する

生成後、そのまま会話を続けます。

```
もっと暖色寄りにして
背景の情報量を減らして
表情をもう少し曖昧に
```

修正のたびに v2, v3... と履歴ファイルに追記されます。

### 完成

```
完成
```

でステータスが「完成」に変わります。

## このリポジトリは「育てて使う」前提です

`/create-prompt` はそのままでも動きますが、最初は誰が使っても似た方向の絵が出ます。
自分の絵柄を出すには、いくつかのカプセルを書き換えていく必要があります。

**書き換えはファイルを直接編集せず、Claude Code に依頼してください。**
「こういう絵にしたい」と日本語で伝えれば、Claude Code がカプセルを更新します。
以下に、そのままコピーして使える依頼テンプレートを置いています。

### 育て方の順序

#### 1. まず動かす

```
/create-prompt 春の公園で団子を食べている猫耳の少女
```

デフォルトの出力を確認する。出てきた絵を見て「ここを変えたい」を集める。

#### 2. 画風カプセルを書き換える（対話テンプレート）

以下の3つは、自分の絵柄を反映する場所です。

| カプセル | 書き換える内容 |
|---------|----------|
| `art-style.md` | 線の扱い・色面の作り方 |
| `coloring.md` | 配色・影色・彩度の基準 |
| `painterly-texture.md` | 画材・質感・筆致 |

書き換えはこう依頼してください。

```
私の絵柄は{こういう感じ}です。
具体的には：
- 線：{細くて控えめ／太くて勢いがある／など}
- 色：{鮮やか／落ち着いた／など}
- 画材：{水彩寄り／油絵寄り／鉛筆／など}

art-style.md / coloring.md / painterly-texture.md を、
私の絵柄に合うように更新してください。
共通骨格（変更しない、と書かれている部分）はそのままにしてください。
```

書き換えのコツや、自分の絵柄をどう言葉にするかは、本書「第5章 自分のスタイルにカスタマイズ」で扱います。

#### 3. キャラクターを登録する（対話テンプレート）

```
新しいキャラクターを characters/ に追加したい。

名前：{ミント}
外見カテゴリ：{人間／猫型特徴を持つ人物／兎型特徴を持つ人物／など}
年齢帯：{少女・10代前半／成人女性／など}
髪：{緑のショートボブ、軽くハネた毛先／など}
目：{黄緑／など}
衣装：{ベージュのカーディガン、白のワンピース／など}
特徴的な要素：{首元の小さな鈴、ぼんやりした表情／など}

characters/_template.md を参考に、ファイルを作ってください。
```

登録すると、名前を含めて呼ぶだけで自動参照されます。

```
/create-prompt ミントが春の公園で団子を食べている
→ characters/ミント.md を自動参照
```

#### 4. スタイルプリセットを足す（対話テンプレート）

```
新しいスタイルプリセットを styles/ に追加したい。

スタイル名：{ink-loose}
狙い：{ペン線をしっかり残し、塗りは控えめにするスタイル}
線質：{線にやや強い存在感、ペン先のかすれを残す}
色面：{薄めの彩色、線が主役で色は補佐}
密度：{線で構造を見せ、塗りは省略を多めに}

styles/_template.md を参考に、ファイルを作ってください。
```

呼び出しは第1引数にスタイル名を入れます。

```
/create-prompt ink-loose 猫娘がお団子を食べている
→ styles/ink-loose.md を自動参照
```

#### 5. 新しいカプセルを足す（対話テンプレート）

```
新しい判断軸を domains/ にカプセルとして追加したい。

ドメイン名：{lighting-mood}
役割：{光と空気感の専門カプセル}
priority：{6}（既存と衝突しない値で）
扱う内容：
- {自然光と人工光の使い分け}
- {時間帯ごとの色温度}
- {影の柔らかさ}

domains/_template.md を参考にカプセルを作って、
他のカプセルと矛盾しないか確認してください。
```

### カスタマイズの設計思想

- ファイルを直接編集する前に、まず Claude Code に依頼する
- 「こう描きたい」を日本語で伝え、Claude Code が視覚的な記述（線・色・密度）に翻訳して書き残す
- 一度書けば、Claude Code が以降のプロンプト生成で常に参照する
- 自分のカスタム指示を、自分の手で育てていける
